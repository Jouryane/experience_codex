## 一条总纲（先立这个，其余才有依据）

**本目录（docs/discussions）是 lvl2 轨道；其余 docs 是 lvl1 轨道。**

| 轨道 | 形态 | 约束对象 | 状态 |
|---|---|---|---|
| lvl1 | experience 在 agent **之外**的插件层 / 外部控制器 | 已建成的项目 | 已交付，不改 |
| lvl2 | agent **原生吸收** experience 作为它的属性 | 尚未存在的形态 | 讨论与规划中 |

现在的问题是：**lvl1 的文档没有一句声明自己是 lvl1 的**，所以读起来像是在
约束 lvl2。这是所有"矛盾"的来源，也是最快的修法。

## 四、新增的正面资产（可以直接进宣发）

实验给出了两条 lvl1 阶段拿不到的、可实测的正面结论：

1. **0 LLM 是可能的，而且已被实测**：E1/E3 里整条遍历 `llm_calls = 0`，
   任务的前 5 步被完整做完，交接被单独计数。
2. **"是否二选一"这个问题的答案是否定的**：不是"experience 识别"或"LLM 总揽"，
   而是**同一个遍历在证据耗尽处切换主体**；`p` 是唯一的模式参数。

这两条建议写进 `why-3-5-layer.md` §3 或 §5，作为"四个硬指标"的实测补充。
