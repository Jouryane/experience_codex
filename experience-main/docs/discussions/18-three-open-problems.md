# 18 · 三个悬而未决的问题

> 2026-09-18。承接 [17](17-three-arm-result.md)。甲方提出三个问题，
> 本文给出分析、可验证点与我的判断。

## 问题一：绕过 LLM 直接执行时，怎么保证命中的经验是对的？

### 1.1 先把张力说准

round 16 的诊断是：**判断成本 ≈ 自己做一遍的成本**。
它的另一面是——**安全性正来自那个判断**。

> 安全性来自判断；节省来自跳过判断。这不是可以同时最大化的两个量。

所以"怎么确保命中是对的"没有免费的答案。但有**三条不靠模型的手段**：

| 手段 | 性质 | 能保证什么 |
|---|---|---|
| **前提的唯一性** | 可静态计算 | 在已知经验集合里，这个状态**只**能满足这一条经验 |
| **可逆性** | 执行期保证 | 匹配错了，代价是一次回滚，不是数据损坏 |
| **留痕** | 事后可审 | 上位机随时可以观测这一步，**不必事前判断** |

### 1.2 关键机制：唯一性是可以证明的，正确性不能

**不能**保证"这条经验是对的"——那要理解用户意图。
**能**保证"这条经验在注册表里是唯一的"——这是集合运算：

```text
对任意两条经验 A、B：
   是否存在一个可观测状态，使 A.pre 与 B.pre 同时为 TRUE？
   是 → 歧义 → 禁止自动执行（或必须先补判别式）
   否 → A、B 互斥
```

这正是实验 E7（判别式自动提取）在做的事，而且它是**纯确定性计算**。
换句话说：**安全性不来自"匹配得对"，而来自"匹配得唯一"。**

### 1.3 一个必须说清的漏洞

**后置判据不能防错配。**

如果本该走 B（写 `b.txt`），却匹配到了 A（写 `a.txt`），那么 A 执行完之后
**A 自己的后置判据是成立的**——"`a.txt` 存在"确实为真。
系统会报告 success，而任务是错的。

> **后置判据验证的是"转移执行了"，不是"这个转移是对的"。**

所以我们此前那句"执行后仍要过判据"在自动执行路径上**给不了我们想要的安全感**。
真正能挡错配的只有 1.2 的唯一性检查 + 1.1 的可逆性。

### 1.4 结论

不能保证"对"，只能保证"唯一 + 可逆 + 可审"。
超出这三条的部分，依赖**注册表是完备的、前提是诚实的**——
那是一条**维护责任**，不是一条可以计算的性质。

这也是为什么我认为：**experience 是域内机制，不是通用 agent 机制。**
在一个特定仓库/组织里，注册表可以做到完备与互斥；
在通用场景里不能。**这不是为了赢而收缩，这是机制的本来性质。**

## 问题二：部分覆盖更差——用"段"和状态交接来解

### 2.1 先重新解释失败的原因

我发给模型的是**一句话声明**："与目标值相关的修复已经完成并由自检验证通过。"

模型不信它，于是重新核查。**关键在于：声明在提示词里，而世界没有以它看得见的方式变化。**
模型无法区分"同伴真的做了"与"有人这么说了"，而核查比信错便宜。

### 2.2 甲方的直觉是对的：不要用文字交接，用状态交接

如果是**状态**被推进了，模型不需要"相信"任何东西——它只要看。
这与"经验是段"的说法一致：段的效果**就是**状态变化。

所以交接的正确形态应该是：

```text
✗ 声明式：把"已完成"写成一句话塞进提示词
✓ 状态式：让世界真的变了；再附一条最小事实
          （经验 id / 执行时间 / 判据证据路径），不做任何论证
```

**可立刻验证的预测**：部分覆盖时**不加那句声明**（只执行、不宣告），
模型的核查成本应该显著低于加声明的情况（14 次请求）。
若成立，原则就是：**不要宣告，改变世界。**

### 2.3 关于"是否把注入的经验变成段"

我认为方向对，但要说准：**变成段的价值不在于省 token，而在于取消"相信"这个动作。**
模型对文本来源的信任度极低（这是它被训练出来的正确习惯），
对**它能自己观测到的状态**没有这个问题。

## 问题三：pull 的不稳定——我认为这不是需要修的问题

### 3.1 我的判断

同一任务、同一经验，四轮里三轮为零、一轮两倍好。**这不是机制的抖动，是决策点问题。**

模型在"调用经验"与"自己做"之间摇摆，说明**它无法判断哪个更便宜**——
如果调用真的稳定省 4 次往返，模型会稳定地调用它（模型擅长选明显更便宜的路径）。

> **高方差本身就是"期望收益贴近零"的证据。**
> 在零点附近的决策，方差天然最大。

所以：**pull 的不稳定不是需要修的问题，是 pull 期望收益 ≈ 0 的证据。**
它与 13–15 三轮的聚合结论一致，只是这一次把它读对了。

### 3.2 因此建议

**停止试图稳定 pull。** 把它当作诊断证据，不作为产品面。
真正值得投入的是 `pre` 那条路，以及它在 1.4 里暴露的唯一性与可逆性工作。
